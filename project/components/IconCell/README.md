# IconCell

Icon tile that lights up in its concept colour on hover.

**Consumer provides** a Lucide icon (26px, stroke 1.5), a one-word name, and a colour token (`--c`).

**Specs** `bg-2`, `border`, radius 13px, padding 16/8; name 9px Space Grotesk 600 uppercase `muted`. Hover: border hue 40%, fill hue 5%, 16px glow, icon in hue and scaled 1.18 on a springy curve. Grid `minmax(100px,1fr)`, gap `space-12`.

*From DesignSystemV3.tsx `IconCell`.*
