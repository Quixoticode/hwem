# Logos

The xSyna mark: an organic X of two curves around a nucleus, filled with the Synaptic Cyan → Neural Amber gradient (the only place a gradient is part of the identity).

- `xsyna-mark.svg` — current mark from the V3 system (quadratic curves, stroke 7, nucleus r9 on `bg`). Use this one.
- `xsyna-mark-guide.svg` — the earlier mark from the brand guide (cubic curves, stroke 8, white core dot). Keep for legacy material only.

Both are self-coloured (`primary`/`cyan-500` → `secondary`, nucleus in `bg`/`cortex`) and made for dark grounds. Minimum size 24px; give it clear space of half its width. Never recolour it in one flat ink, never put it on a light ground.
