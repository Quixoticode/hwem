# LoaderConcepts

Twelve new loader concepts for moments the V3 set doesn't cover — each one a small piece of neuroscience in motion. Intentional additions, not in the source; see the Loading section for when to use which.

**The set** Spike train (inference on the xSyn chip) · Synapse link (pairing devices, connecting SynAIs to the collective) · Mitosis (spawning or forking an agent) · Mesh weave (learning, building an index) · Echo search (searching memory or knowledge) · Consolidate (writing to memory, saving) · Liquid fill (upload/save with known %) · EEG scan (health check, monitoring) · Voice cortex (listening to voice input) · Mark draw (app launch, splash) · Privacy seal (encrypting, local-only processing) · Liquid skeleton (content placeholder).

**Rules they share** built only from tokens (`primary`, `secondary`, `accent`, `success`, `border`, `bg`); one hue per meaning — cyan = system/electric, amber = human/private/collective, violet = memory/learning, green = health/live; loops 1.1–2.8 s on `cubic-bezier(.65,0,.35,1)` or `(.16,1,.3,1)`; 24–120px wide; always paired with a mono status line when shown longer than 2 s; static under reduced motion.

*Concepts by design, CSS/SVG in `bundle.css` (classes `nl-c-*`).*
