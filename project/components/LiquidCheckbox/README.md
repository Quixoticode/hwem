# LiquidCheckbox

Checkbox whose tick pops in with a spring.

**Consumer provides** `checked`, `onChange`, label children (13px/1.55 `muted`).

**Specs** box 19px, `radius-xs`, border 1.5px `muted` at 33% → `primary` when checked, checked fill `primary-tint`; Lucide check 10px stroke 3 in `primary`, scales 0→1 (spring 600/22).

*Hand-written from DesignSystemV3.tsx `LiquidCheckbox`.*
