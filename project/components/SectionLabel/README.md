# SectionLabel

Section header for long pages: numbered mono overline with a fading rule, a big title and a muted subtitle.

**Consumer provides** `n` ("01 / INTERACTIONS"), `title`, `sub`.

**Specs** overline `overline` in `primary`, rule 1px `primary-line` → transparent; title `section-title` (clamp 26–42px); sub `body` in `muted`, max 520px; 48px (`space-48`) below.

*From DesignSystemV3.tsx `SectionLabel`.*
