# Chip

Three small labels: suggestion chip (clickable prompt), badge (plan or status) and mono tag (code names).

**Specs** chip: 6/12 padding, `radius-2xl`, `primary` 4% fill / 19% border, 12px DM Sans `primary`. Badge: 4/10, `radius-2xl`, Space Grotesk 700 10px +0.06em, `primary` 8%/19%. Tag: 3/7, `radius-tag`, JetBrains Mono 9px, `primary` 5%/13%.

*From DesignSystemV3.tsx (chat suggestions, profile PRO badge, "Components used" tags).*
