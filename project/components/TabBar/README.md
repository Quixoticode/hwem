# TabBar

Segmented tab bar with a liquid indicator that springs to the active tab.

**Consumer provides** the tab labels and the active index.

**Specs** container `bg-2`, `border`, `radius-lg`, padding `space-4`; tab 9/18 padding, Space Grotesk 600 13px, `muted` → `primary` when active; indicator `primary-tint` fill, `primary-line` border, `radius-sm`, spring 400/30. Content below fades in with blur.

*Hand-written from DesignSystemV3.tsx `TabBar` (static indicator per tab in the CSS rendition).*
