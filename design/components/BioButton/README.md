# BioButton

The brand guide's outline pill: a transparent capsule with a cyan border through which a light pulse sweeps on hover.

**Use** for secondary calls on marketing pages and hero sections; in product UI prefer `LiquidButton` ghost.

**Consumer provides** the label; add `is-active` for the selected state.

**Specs** `radius-pill`; border 1px `rgba(0,240,255,.5)`; hover/active fill `rgba(0,240,255,.15)`, glow `0 0 20px rgba(0,240,255,.2)`, border `cyan-500`; the sweep is a 90° transparent→20% cyan→transparent band moving left→right in 0.5s.

*From the brand guide §5.2 (CSS given there verbatim).*
